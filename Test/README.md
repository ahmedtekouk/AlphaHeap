# AlphaHeap Test Files
 There is the files for test the library `AlphaHeap` in real c code 

## Test Directory Structure
```text
    Test/
    ├── files
    │   ├── htest
    │   ├── test.c
    │   └── test.exe
    └── README.md
```

## How to use
1. Compile the code using this command
```bash
gcc -o test Test/files/test.c src/aheap.c
```
2. Run the program using this command in Linux or Unix systems :
```bash
./test
```
3. or in windows :

```bash
./test.exe
```
